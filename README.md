# Porsche Sales Intelligence | Dashboard de Vendas

Dashboard interativo de análise de vendas de veículos Porsche, desenvolvido como projeto prático de curso, com interface inspirada na identidade visual da Porsche Brasil.

## Objetivo

Transformar uma base de vendas sanitizada em informações visuais para apoiar análises comerciais, como identificar os modelos mais vendidos, comparar resultados entre cidades e estados e examinar a distribuição por ano-modelo.

## Funcionalidades

- Indicadores-chave de desempenho (KPIs) de vendas.
- Filtros interativos por modelo, ano-modelo, cidade, estado e método de pagamento.
- Comparação dos modelos vendidos por cidade.
- Análise da distribuição das vendas por ano-modelo.
- **Vendas por State (Estado)**, com ranking por volume.
- Insights comerciais baseados nos filtros selecionados.

## Tecnologias

- HTML, CSS e JavaScript.
- Chart.js para gráficos interativos (carregado por CDN; é necessária conexão à internet).

## Como executar

1. Baixe o repositório ou abra o site publicado pelo GitHub Pages.
2. Abra `index.html` em um navegador moderno.
3. Explore os filtros e gráficos. Não é necessário instalar dependências.

## Publicação com GitHub Pages

Em **Settings > Pages**, selecione **Deploy from a branch**, a branch **main** e a pasta **/(root)**. Salve. O GitHub fornecerá o endereço público após a publicação.

## Dados e limitações

O dashboard utiliza dados sanitizados incorporados ao arquivo HTML para demonstração. Alguns registros possuem datas inválidas; análises temporais devem considerar apenas datas válidas. Antes de publicar, confirme que o conjunto sanitizado pode ser divulgado publicamente.

## Aviso

Projeto acadêmico independente, sem vínculo, patrocínio ou endosso da Porsche. A referência visual à marca é utilizada exclusivamente para fins educacionais.
